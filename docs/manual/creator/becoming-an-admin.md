# Becoming an admin

Admins look after an area: they review creator requests there, manage the
creators working there, and moderate its polls. You need to be a creator to
ask.

## Sending a request

1. On your Creator dashboard, click **Request admin access**.
2. Choose the area: one or more **whole states**, or **Nationwide**.
3. Optionally add a **Reason**.
4. Click **Submit Request**.

A super reviews it, and you'll get an email: **"You are now an Admin!"** or
"Your admin request was not approved".

## Once you're an admin

- **Admin** appears in the top bar, with your Admin dashboard. See [Reviewing
  creator requests](../admin/reviewing-creator-requests.md), [Managing
  creators](../admin/managing-creators.md) and [Managing
  polls](../admin/managing-polls.md).
- **You're also a creator across your admin area.** You get creator access for
  the same states, so you can create polls there. It's ordinary creator access:
  you, or another admin of that state, can switch it off on Manage Creators.
- **To cover more states,** use **Request more admin coverage** on your Admin
  dashboard.

Admins keep paying for their membership like every other member. If it lapses,
you lose admin access too.

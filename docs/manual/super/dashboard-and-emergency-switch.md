# Your Super dashboard and the emergency switch

**Super** in the top bar opens a menu: **Super** (your dashboard), **Admin** and
**Create**. Supers oversee the whole
system: you can do everything an admin can, everywhere, plus the tools below.
Supers don't need a paid membership.

## The tools

- [Admin Requests](admin-requests.md): approve people asking to become admins.
- [Manage Users](managing-users.md): find any account, switch it on or off,
  change roles, and send messages.
- [Manage All Polls](managing-all-polls.md): correct the title, summary or close
  date of any poll.
- [Poll Templates](poll-templates.md): how each poll type is set up, such as how
  voters choose in elections.
- [IP Allow / Deny](ip-rules.md): lists of addresses (not enforced yet).

**Results:** you see every poll's results **live, with exact counts**, at any
size (a note on the results page says so). Everyone else sees results only from
4 respondents, updated in steps of 4, as rounded percentages.

The admin pages work for you too, across the whole country: see [Managing
creators](../admin/managing-creators.md) and [Managing
polls](../admin/managing-polls.md).

## Admin workload

**Admin Workload** shows how creator requests are spread across admins: each
admin's **Pending** requests, their **% of total**, and how many are **Stale**
(waiting more than 48 hours). A ⚠ marks an admin whose share is unusually
large. Click **Refresh** to update it.

If one admin is swamped or a request is stuck, approve or reject it yourself,
or ask another admin of that state to pick it up.

## Switching off all poll submissions

**Poll submissions** shows whether people can currently answer polls.

**Disable all submissions** stops everyone, everywhere, from submitting answers,
straight away. Viewing polls, searching and results keep working. It's meant
for emergencies, for example if something is going wrong with voting. You're
asked to confirm.

While it's off, anyone trying to answer sees "Poll submissions are temporarily
disabled by an administrator". Click **Re-enable submissions** to turn them
back on.

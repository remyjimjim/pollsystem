# Admin requests

Creators ask to become admins with **Request admin access** (see [Becoming an
admin](../creator/becoming-an-admin.md)). Every admin request comes to the
supers.

**Admin Requests** lists the pending ones: who asked, the **Area** (whole
states or nationwide), their reason, and when they asked.

- Tick one or more requests, then click **Approve selected** or **Reject
  selected**.
- **Refresh** reloads the list.

The person gets an email either way. When you approve:

- they become an admin of that area;
- they also get creator access across the same area, so they can create
  polls there. It's ordinary creator access, which they or another admin of
  that state can switch off on Manage Creators.

To take admin access away later, use **Demote** on [Manage
Users](managing-users.md).
